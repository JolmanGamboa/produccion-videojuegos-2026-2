# Producción de Videojuegos - Sistemas Interactivos 2026
**Universidad Antonio Nariño**

## Descripción
Este repositorio aloja la línea base del proyecto integrador interactivo desarrollado durante el semestre académico 2026-2.

## Estructura del Proyecto
El desarrollo sigue una arquitectura estructurada en carpetas dentro del directorio `src/`:
* `src/scenes/`: Contenedor de pantallas y flujos del sistema.
* `src/scripts/`: Lógica GDScript pura para el control de la aplicación.
* `src/assets/`: Recursos multimedia clasificados.

## Tecnologías Utilizadas
* **Godot Engine 4.x** (Renderizador: Compatibility)
* **GDScript** (Tipado estricto)
* **Git/GitHub** para control de configuración
